# War Impact Desk ⚡

> **전쟁·제재·공급망 리스크를 업무 액션으로 바꾸는 AI Agent**
>
> 단순한 뉴스 모니터링을 넘어, 지정학 이벤트를 기업의 산업과 공급망 기준으로 판단하고 즉각적인 대응 액션과 경영진 보고서 초안까지 자동 생성하는 B2B 리스크 인텔리전스 프로토타입입니다.



---

## 🚀 아키텍처 및 데이터 파이프라인

본 프로젝트는 프로토타이핑 검증 목적을 위해 **데이터 수집 레이어**와 **AI 분석 레이어**를 분리하여 구현했습니다.

### 1. 실시간 데이터 수집 (Real-time Pipeline)
- **사용 데이터:** `GDELT 2.0 API` (위기/분쟁/제재 카테고리 필터링 적용)
- **설명:** 지도(실시간 관제) 페이지는 전 세계 뉴스 이벤트를 모으는 공개 데이터베이스 GDELT의 실시간 API를 연동하여 최근 24시간 내 발생한 전 세계 분쟁 및 제재 뉴스 데이터를 오버레이합니다.

### 2. 실시간 AI 분석 (`/live`, `api/live-analysis.js`) — 실데이터 + 실제 LLM
- **흐름:** GDELT DOC 2.0 API에서 최근 24시간 영문 뉴스(제재·수출통제·해상 공격·관세·전쟁) 목록 수집 → 중복 제거 후 최대 25건 → Vercel 서버리스 함수에서 **Gemini API**가 선택 산업 기준으로 영향이 큰 사건 최대 5개를 구조화
- **출력:** 사건 제목, 지역, 카테고리, 리스크 점수(0~100), 왜 중요한가, 사업 영향, 이번 주 확인할 행동, 확신도, **근거 기사 링크**
- **통제 장치:**
  - 응답을 JSON 스키마로 강제하고, 카테고리 목록 밖의 값이나 근거 기사 번호가 실제 목록에 없는 항목은 버립니다.
  - 제목에 없는 수치(금액·%·물량)를 만들지 말라고 지시하고, 제목만 근거로 쓰므로 확신도를 함께 표시합니다.
  - API 키(`GEMINI_API_KEY`)는 서버 환경변수에만 두고 브라우저로 보내지 않습니다.
  - GDELT는 클라우드 서버 IP를 자주 제한(429)해서, **뉴스는 방문자 브라우저가 GDELT에서 직접 받고(CORS 허용) 서버는 Gemini 분석만** 합니다. 서버는 브라우저가 보낸 목록을 믿지 않고 다시 검증합니다(최대 25건, http(s) 링크만, 길이 제한, 중복 제거).
  - 같은 산업·같은 기사 묶음은 30분 캐시해 Gemini를 다시 부르지 않습니다. Gemini가 429·503이면 `gemini-2.5-flash` → `gemini-2.5-flash-lite`로 넘깁니다.
  - 실시간 수집이 막히면 `snapshot/latest.json`(마지막으로 수집에 성공한 기사와 산업별 분석)을 **수집 시각과 함께** 보여 줍니다. 스냅숏은 `node scripts/snapshot.js`로 만듭니다.
- **배포 설정:** Vercel 프로젝트 Settings → Environment Variables에 `GEMINI_API_KEY` 추가

### 3. 시나리오 데이터 (대시보드·이벤트 모니터·브리핑) — 시연용
- **사용 데이터:** 실재했던 과거 지정학 리스크 이벤트 12종을 바탕으로 **사전에 작성한 시나리오** (`data.js`)
- **설명:** 리스크 스코어링, 비즈니스 영향도, 대응 액션 체크리스트를 정해진 JSON 형태로 만들어 화면 구성을 검증하는 용도입니다. 이 메뉴들의 점수·문장은 LLM이 실시간으로 만든 것이 아닙니다.

## 🛠 기술 스택 (Tech Stack)

### Frontend
- **Core:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Map & Dataviz:** Leaflet.js, CartoDB Dark Matter BaseMap
- **Architecture:** Zero-dependency (최소한의 외부 라이브러리로 가볍고 빠른 성능 유지)
- **State Management:** LocalStorage API (사용자 산업/키워드 설정 저장)

### Deployment
- **Vercel:** 정적 파일 빌드 및 글로벌 Edge Network 배포 (`vercel.json` 커스텀 라우팅 적용)

---

## 🎯 핵심 기능 (Key Features)

- 📊 **산업 맞춤형 대시보드:** 소속 산업군(반도체, 에너지 등)에 따라 리스크 중요도와 대응 액션이 동적으로 재설정됩니다.
- 🗺️ **글로벌 실시간 관제:** Leaflet DarkMap 기반으로 실시간 분쟁 이슈 산발 지점을 추적하고, 리스크 심각도에 따라 펄스 애니메이션이 적용된 관제 환경을 제공합니다.
- 📋 **AI 보고서 자동 생성:** 선택한 모니터링 이벤트를 종합하여 3가지 유형(경영진 브리핑, 실무 상세, 액션 체크리스트)의 리포트를 자동 생성합니다.
- ⚡ **실행 가능한 액션 도출:** "우려된다"가 아닌, "물류 경로 B플랜을 확보하라" 같은 실무적 대응 체크리스트를 도출합니다.

## 📁 프로젝트 구조 (Directory Structure)

```text

├── index.html       # 제품 소개 랜딩 페이지
```
